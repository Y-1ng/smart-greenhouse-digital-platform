# 开发脚本说明

| 双语文件 | 中文说明 |
| --- | --- |
| `检查项目结构_check-structure.ps1` | 检查前端、后端、合约和部署目录是否完整 |
| `启动基础设施_start-infra.ps1` | 启动 MySQL、Redis、MinIO 和 EMQX |
| `启动演示系统.cmd` | 用 jar 启动后端（`demo` 配置、默认 8090）、前端开发服务器（默认 5199）、物联网服务（非 Web 模式）和设备指令模拟器，然后打开登录页；端口已被占用时不会重复启动，启动失败会自动打印日志末尾。**需在 Windows 资源管理器里双击，IDEA 中双击只会打开文本** |
| `停止演示系统.cmd` | 停止由本项目启动的后端、物联网服务和设备模拟器；加 `-IncludeFrontend` 可同时停止前端开发服务器，加 `-KeepIot` 可保留物联网服务和设备模拟器。端口被 IDEA 等其它程序占用时只提示、不误杀 |
| `模拟设备_telemetry-simulator.ps1` | 手工模拟设备上报温湿度、光照和土壤水分遥测，支持告警演示和预览模式；`demo` 配置默认已自动注入遥测，需要手工控制节奏时使用 |
| `模拟设备_command-simulator.ps1` | 扮演设备回执：轮询已下发指令并调用回执接口，演示「指令下发 → 设备执行 → 状态收敛」闭环，支持 `-FailOnce` 演示失败分支 |
| `编译智能合约_compile-contract.ps1` | 用 solc-js 编译存证合约，输出 ABI 并打印函数数量与字节码大小 |
| `验证真实上链_real-chain-smoke-test.ps1` | 检查链上适配服务与 FISCO BCOS 节点连通性，写入五类存证交易并验证重复存证幂等、篡改内容被拒绝 |

脚本只封装常用本地命令，不保存任何生产环境密码。

`启动演示系统` 的补充说明：

- 隐藏窗口启动时后端日志写入同目录 `运行日志_后端.txt` 与 `运行日志_后端_错误.txt`，脚本会在启动失败时自动把日志末尾打印到控制台。
- 物联网服务和设备模拟器日志写入 `运行日志_物联网.txt`、`运行日志_物联网_错误.txt`、`运行日志_设备模拟器.txt` 与 `运行日志_设备模拟器_错误.txt`。
- 想看实时日志：`powershell -ExecutionPolicy Bypass -File .\启动演示系统.ps1 -Visible`，后端改用可见窗口启动。
- 启动脚本会等待后端监听 8090，并等待物联网服务日志出现 `Started IotApplication` 后再启动设备模拟器，启动较慢的机器不会误判失败。

`验证真实上链_real-chain-smoke-test.ps1` 默认访问 `http://192.168.88.141:8600`（实训环境虚拟机上的适配服务），可用 `-Adapter` 指定其它地址、`-Tag` 指定业务标识避免重复：

```powershell
powershell -ExecutionPolicy Bypass -File .\验证真实上链_real-chain-smoke-test.ps1 -Adapter http://192.168.88.150:8600
```
