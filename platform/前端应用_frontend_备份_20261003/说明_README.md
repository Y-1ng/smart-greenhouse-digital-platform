# 前端应用说明

本模块使用 Vue 3、TypeScript 和 Vite，包含数字孪生首页、生产指挥、质量溯源、合作运营和治理决策五个业务区域。

首页采用“园区温室选择 + 单棚数字孪生”的两阶段体验，支持多个温室悬停选择、鼠标视差、拖动旋转、滚轮缩放、热点聚焦、图层切换、自动环视和全屏查看。

## 页面能力

| 页面 | 主要能力 |
| --- | --- |
| 生产指挥 | 温室选择、新增大棚、改种和删除统一弹窗，内置 80 种以上西北适种作物与品种建议；环境摘要按阈值实时判定（正常/偏低/偏高/告警）、指标卡点击弹出阈值调节、“阈值联动”按控制动作下发设备指令、设备开关与通风联动、今日水肥计划、环境周期趋势图、周期根哈希可视化；每 20 秒自动刷新并显示更新时间 |
| 质量溯源 | 按产品编码或田块编号查询、核验印章、环境/合格证/一物一码三张存证卡、哈希指针链（断链标红）、模拟消费者扫码（首次验证 / 重复扫码风险）、电子合格证 Ed25519 验签与篡改演示、检测报告上传、合格证备案、一物一码生成 |
| 合作运营 | 合作村庄、入股土地、本期分红、平均股权指标，分红与股权分布图，入股与分红表单 |
| 治理决策 | 接入温室、设备在线率、待处理预警、溯源覆盖率，风险明细来自设备离线、链上待确认与重复扫码统计 |
| 首页 | 园区多温室选择 + 单棚数字孪生，支持悬停选择、鼠标视差、拖动旋转、滚轮缩放、热点聚焦、图层切换、自动环视和全屏 |

所有业务页均调用后端 REST API；后端不可用时页面给出降级提示，生产页保留本地演示数据用于界面预览。

## 目录

| 名称 | 中文说明 |
| --- | --- |
| `src/api` | 后端 REST API 客户端 |
| `src/components` | 可复用界面组件 |
| `src/router` | 页面路由和菜单元数据 |
| `src/stores` | Pinia 状态管理 |
| `src/styles` | 全局样式与设计变量 |
| `src/views` | 首页和四个业务区域页面 |
| `src/components/greenhouse` | 园区多温室总览、单棚数字孪生与交互热点 |
| `src/data` | 温室场景、设备、终端、指标演示数据及西北适种作物目录 |
| `src/types` | TypeScript 接口类型 |

## 启动

```powershell
npm install
npm run dev
```

开发服务器默认运行在 `http://localhost:5199`，并把 `/api` 代理到 `http://localhost:8090`（可用环境变量 `VITE_API_PROXY_TARGET` 指向其它后端地址）。

## 校验命令

```powershell
npm run type-check   # vue-tsc 类型检查
npm run build        # 类型检查 + 生产构建，产物输出到 dist/
```
