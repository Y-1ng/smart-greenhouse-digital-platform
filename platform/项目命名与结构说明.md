# 项目命名与结构说明

平台采用“中文用途名 + 英文技术名”的双语目录命名方式，便于阅读项目结构，同时保留 Maven、Node.js、Solidity 和容器工具链需要的英文标识。

| 目录或文件 | 中文用途 |
| --- | --- |
| `前端应用_frontend` | Vue 3、Three.js 数字孪生首页、管理端和移动端页面 |
| `后端服务_backend` | Spring Boot Maven 父工程 |
| `公共模块_greenhouse-common` | 统一响应、错误码和业务异常 |
| `业务服务_greenhouse-api` | REST 接口、业务编排、权限和链上适配 |
| `物联网服务_greenhouse-iot` | MQTT 设备接入、遥测接收和控制回执 |
| `智能合约_contracts` | Solidity 合约源码和部署说明 |
| `部署配置_deploy` | MySQL、Redis、MinIO 和 EMQX 容器环境 |
| `开发脚本_scripts` | 环境检查和本地开发辅助脚本 |
| `项目说明_README.md` | 总体启动方式和模块导航 |

Java 包名、Maven `artifactId`、NPM 包名、Vue 组件名、API 路径和 Solidity 函数名属于工具链标识，继续保持英文。

## 推荐阅读顺序

1. 阅读 `项目说明_README.md` 了解总体启动方式。
2. 阅读 `前端应用_frontend/说明_README.md` 了解页面结构。
3. 阅读 `后端服务_backend/说明_README.md` 了解服务拆分。
4. 阅读 `智能合约_contracts/说明_README.md` 了解存证数据。
5. 阅读 `部署配置_deploy/说明_README.md` 启动本地基础设施。
