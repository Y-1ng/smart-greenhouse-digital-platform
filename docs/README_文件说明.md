# 文件夹说明

本文件夹是“智慧温室大棚农产品全链条数字化管理平台”的毕业设计总体方案材料。

## 文件说明

- `01_毕业设计项目总体设计文档.docx`：主交付文档，包含摘要、需求、功能、架构、数据、接口、权限、实施计划、测试、风险和 AI 使用记录。
- `02_需求分析.md`：需求分析的 Markdown 版本，便于继续修改。
- `03_总体设计初稿.md`：与 Word 主文档对应的 Markdown 版本。
- `04_数据库初始化脚本.sql`：由后端 Flyway 迁移 V1~V20 汇总生成的 MySQL 建表脚本，共 21 张表，与实际运行结构一致。
- `05_后端与智能合约接口清单.md`：REST、MQTT 和智能合约接口。
- `06_AI使用与核验记录.md`：AI 辅助步骤和人工选择说明。
- `07_答辩演示要点.md`：演示前准备、五步演示流程、项目介绍和常见答辩问题。
- `08_技术方案.md`：技术选型、模块实现、数据存证、接口、安全、部署、测试和交付标准。
- `09_测试与验证记录.md`：后端测试、前端构建、接口冒烟和浏览器端到端验证记录。
- `10_论文与实现一致性核对表.md`：docx/markdown 设计文档与当前实现的逐条对照，标出需要改口径的 10 处表述、可直接引用的实测证据与定稿待补清单。
- `11_无头浏览器功能走查记录.md`：用无头 Chromium 逐项执行 32 个业务功能并截图的结果（当前 32/32 通过），截图存放于 `验证截图_20260919/`。

五张设计图（系统功能结构图、核心业务流程图、系统逻辑架构图、0 层数据流图、哈希链与一物一码存证图）位于仓库根目录 `diagrams/`，每张同时提供 PNG 和 Mermaid 源文件。

## 提交前需要补充

1. 按学校要求填写封面上的姓名、学号、班级、学院和指导教师。
2. 核对学校格式要求，例如字体、行距、页码、目录和参考文献格式。
3. 如果学校要求真实参考文献，请补充自己实际查阅并核验过的资料。
4. 将课程要求中的项目周期和开发技术替换为最终确定版本（区块链平台已确定为 FISCO BCOS 2.8.0，部署与授权记录见 `08_技术方案.md` 第 5.5 节、`09_测试与验证记录.md` 第 9 节）。

5. 按 `10_论文与实现一致性核对表.md` 调整文中表述：WebSocket、视频、时序数据库、合同/订单/议事、冷链/碳效等属于预留或后续扩展，避免与实现不一致。
