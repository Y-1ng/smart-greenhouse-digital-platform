# 论文与实现一致性核对表

用途：把 `01_毕业设计项目总体设计文档_完善版.docx` 与 `03_总体设计初稿.md` 里的表述逐条对照当前代码与实测结果，
标出**可以直接写**、**需要改口径**和**属于后续扩展**的内容，避免答辩时被追问"文档写了但系统里没有"。

核对时间：2026-09-19。核对方式：以仓库代码、Flyway 迁移 V1–V20、后端 68 + 物联网 10 个自动化用例和真链实测记录为依据。

## 一、总体结论

- 文档描述的核心业务闭环（环境采集 → 根哈希存证 → 智能调控 → 水肥执行 → 检测与合格证 → 一物一码 → 消费者扫码 → 合作运营 → 治理监管）**全部已实现并跑通**。
- 区块链相关表述**低于**实际完成度：文档写的是"合约骨架 + 课程节点"，实际已完成真链部署、角色授权、五类存证、待补偿重试与追溯节点幂等上链。
- 有 **10 处表述需要调整口径**：WebSocket、视频、时序库、合同/订单/议事、冷链/碳效、FISCO 版本号、大屏/移动端形态、农事与营养图谱、合格证撤销、设备运维。
